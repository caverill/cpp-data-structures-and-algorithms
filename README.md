# C++ Data Structures & Algorithms

A hands-on repository documenting **C++**, **data structures**, and **algorithms** from the ground up.

The goal of this repository is not just to solve problems, but to understand **why things work** — from memory and pointers to the implementation and efficiency of common data structures and algorithms.


## Build & Run

The exercises are written in C++ and compiled with Clang on macOS.

Compile an example:

```bash
clang++ example.cpp -o build/example
```

Run it:

```bash
./build/example
```

Generated build files are kept out of version control.
